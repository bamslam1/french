FrançaisFlash

This game is designed to help you practice your French skills by providing a French phrase or word and you answer them in the input field. Your score is saved by each gamemode. Reloading the site will bring your most recently played gamemode's score up. Reloading the site will not result in a free phrase reroll (Patched in v5.2.3).

Please note that rerolling the phrase will take off one point.

    If you are experiencing an error that reads "This mode is unavailable" it means,
    (1) your internet is unreachable,
    (2) the date to play the mode has passed,
    (3) a bug has occurred. If so, report it, even if you aren't sure.
    Please note: The limited time modes only last until the end of the month.

    If you are experiencing an error that reads "Unable to fetch date" it means,
    (1) your internet is unreachable,
    (2) a bug has occurred. If so, report it, even if you aren't sure.

    If you are experiencing an error that reads "No Phrases" it means,
    a bug has occurred and JavaScript isn't assigning the phrases properly.

    If you are experiencing an error that reads "Per-gamemode score setup failed: (extra error info)" inside the console it means,
    a bug has occurred when showing the score for the gamemode that you last played.

    If you are experiencing an error that reads "Unable to begin bgm playback" this means,
    a bug has occurred in the proccess of playing the bgm file.

    If you are experiencing an error that reads "API request failed" this means,
    (1) your internet is unreachable,
    (2) a bug occurred.

    If you are experiencing an error that reads "Unable to stop sound" it means the game was unable to stop the jeopardy sound due to,
    (1) a bug occurring.

    If you are experienching an error that reads "Failed to set define button" it means the new define button couldn't be assigned a link to redirect the user to due to,
    (1) saved phrase not having the definition property to read and set the define button link to. This happens to every user already using the site on a particular gamemode.
    (2) A bug has occurred.

    If you are experiencing an error that reads "TTS FAIL" it means,
    (1) your browser doesn't support text to speech (tts),
    (2) a bug has occurred.

    If the game freezes, check the console and take a screenshot or copy the text into a bug report.

    Bugs

    1. When in custom mode, adding only two phrases causes only the first one to be displayed every round.
